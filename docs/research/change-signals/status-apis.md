# API báo trạng thái tài khoản và video (D3)

Kiểm tra tài liệu công khai ngày **2026-11-10**. Phạm vi là connector creator/Page/professional thông thường. Partner/CMS, Rights Manager và Marketing API có quyền khác. Không gọi endpoint cần tài khoản. UI có thể khác theo ngôn ngữ, account type và rollout.

**API** là tín hiệu trực tiếp trong phạm vi nêu. **Một phần** là API chỉ có proxy hoặc chỉ bao phủ một điều kiện. **Thủ công** nghĩa là chưa thấy API công khai chính thức trong phạm vi. Tiền tố scope Google là `https://www.googleapis.com/auth/`. Với Meta cần kiểm đúng login flow, token type, access level và quyền asset. Graph limit và publishing cap là hai giới hạn riêng. [Graph rate limiting](https://developers.facebook.com/docs/graph-api/overview/rate-limiting/)
