# Thông báo deprecation và lỗi API (D2)

Kiểm tra **2026-11-10–11**. Cửa sổ mốc quá khứ 2023-11-11 đến 2026-11-11. Ngày trong bảng là ngày nhà cung cấp công bố hoặc ngày có hiệu lực ghi rõ; mốc trước 2025-11-11 là lịch sử hơn 12 tháng. `null` nghĩa là chưa xác minh từ tài liệu công khai. Không coi changelog HTML, email hay status feed báo outage là feed release. Các RSS/Atom được liệt kê đã trả HTTP 200 với item/entry; Atom Meta dùng chung hai bề mặt. Các site Meta trả 403/429 hoặc thiếu thân bài được đối chiếu với feed chính thức và Postman workspace Meta khi có. Số hạn mức là contract tài liệu, chưa đo bằng credential.

Nguồn provider trong repo, chỉ lấy tên từ [LLM](../../../apps/server/src/providers/llm/registry.ts), [TTS](../../../apps/server/src/providers/tts/registry.ts), [Images](../../../apps/server/src/providers/images/registry.ts), [Footage](../../../apps/server/src/providers/footage/registry.ts) và [Music](../../../apps/server/src/providers/music/registry.ts). Một upstream lặp ở nhiều registry được gộp. Native/remote, API/CLI và phiên bản tương thích vẫn được phân biệt ở hàng tương ứng. Mock và nhạc local không có upstream. Custom route phụ thuộc cấu hình người dùng.

## Cách đọc sự kiện lỗi

- **Vòng đời:** lưu bề mặt, phiên bản yêu cầu và phiên bản thực trả nếu có. Khi nhận `Warning`, `Deprecation` hoặc `Sunset`, lưu giá trị và URL docs có liên quan, đối chiếu ngày công bố và hiệu lực. Chỉ Unsplash có header cảnh báo deprecation đã xác minh ở đây. Header quota, version, request ID và Retry-After thuộc nhóm khác. [Unsplash](https://unsplash.com/documentation) · [Pexels Help](https://help.pexels.com/hc/en-us/articles/900005368726-How-do-I-see-how-many-requests-I-have-remaining)
- **Auth/quota:** so HTTP status với provider code, operation, bucket và scope. Dùng lỗi kiểu 429 cho backoff đúng bucket, hết tín dụng khác rate, 401/190 không nói tài khoản bị cấm. Streaming có thể lỗi sau HTTP 200. Không lưu token hoặc request có chứa credential. [Graph error handling](https://developers.facebook.com/docs/graph-api/guides/error-handling/) · [OpenRouter](https://openrouter.ai/docs/api/reference/errors-and-debugging)
- **Lỗi ngữ nghĩa:** ví dụ YouTube `mostPopular` và alias DeepSeek có thể thành công HTTP nhưng đổi ý nghĩa. Lấy changelog và kết quả schema/metric định kỳ làm bằng chứng riêng, đừng tự động đổi cấu hình sau một request lỗi. [YouTube](https://developers.google.com/youtube/data/revision_history) · [DeepSeek](https://api-docs.deepseek.com/updates/)
- **Cấp mới:** trang Pexels Help là tín hiệu sớm hơn lỗi gọi API bằng key cũ. Chỉ cập nhật khả năng onboarding từ nguồn phù hợp. [Pexels Help](https://help.pexels.com/hc/en-us/articles/900004904026-How-do-I-get-an-API-key)
