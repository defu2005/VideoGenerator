# TASK-041 — Cursor guide (editing skills: transitions, emphasis, animated subtitles, edit plan)

Read `docs/cursor/README.md` and `TASK-040.md` first (TASK-040 is committed: voice tracks have `words` timings). The user says the videos feel flat: dull transitions, no emphasis moments, and subtitles that are hard to notice. Here is the render today:
- `packages/shared/src/render/plan.ts`: per-scene clips with Ken Burns `zoompan` plus fade in/out to black, joined with concat;
- `buildFinalPlan` burns one plain white ASS style;
- `packages/shared/src/subtitles/index.ts` (`toAss`) produces cues with ~0.5 s gaps between them, so subtitles blink off.

This task makes the edit lively while keeping the voice timing exact.

No new npm dependencies. Everything stays ffmpeg filters plus ASS.

## 0. Ground rule: voice sync
Scene start times in the timeline are fixed by the voice. Effects must never shift the audio.
- Transitions overlap clips by extending the **outgoing clip's tail** by the transition duration: hold or continue the motion. The incoming scene still starts exactly at its timeline `startSec`.
- `xfade` offsets are computed from the timeline `startSec`, not from the clip lengths.
- Add a test that the voice/scene starts in the final plan equal the timeline starts within 1 frame.

## 1. Transitions (`xfade`)
- New timeline field per scene boundary: `transition: { type, durationSec }`.
  - Supported types are a curated subset of ffmpeg `xfade`: `fade`, `fadeblack`, `dissolve`, `smoothleft`, `smoothright`, `slideup`, `wipeleft`, `circleopen`, `zoomin`, `radial`, `hblur`, plus `cut` (none).
  - Duration: 0.25–0.8 s, default 0.4.
- Replace the concat-only join with an xfade chain. Many scenes make a long filter chain, so build it in groups of ≤ 12 clips with intermediate files when needed. Keep a concat fallback when ffmpeg lacks `xfade` (capability probe), with a warning.
- The default rhythm when no plan exists (§5):
  - `cut` between most scenes;
  - a soft `dissolve`/`fade` at topic changes;
  - a dynamic one (`smoothleft`/`zoomin`) after the hook scene.
  - Never more than 2 identical non-cut transitions in a row.
- The old per-scene `fadeInSec`/`fadeOutSec` stay only for the first and last scene (fade from/to black).

## 2. Motion variety
- Extend `zoompanExprs` presets:
  - `push_in`, `pull_out`;
  - `pan_left`, `pan_right`, `pan_up`;
  - `punch_in` (a fast 1.0→1.12 zoom over 0.25 s, then hold), used for emphasis;
  - `static` (with a 1.02 breathing zoom).
- Easing stays smoothstep, except `punch_in`, which uses ease-out.
- The default assignment alternates the directions between neighbouring scenes, so two scenes in a row never pan the same way.

## 3. Emphasis moments
Emphasis points are words or phrases in the narration with times from `voice_tracks.words`. Per emphasis point, these effects can be combined:
- **`punch_in`:** a zoom on the visual for 0.25 s at the word start, held for the rest of the phrase, then eased back.
- **`callout`:** a big keyword text pop on screen (ASS on a separate layer, the `Callout` style):
  - scale-in animation with `\t(\fscx120\fscy120…)` → 100;
  - a highlighted box or colour from the profile brand colour;
  - position top or center (never covering the subtitles);
  - duration = phrase length + 0.3 s.
- **`flash`:** a 2-frame white flash (`fade` with a white `color` source overlay) for big reveals, used rarely.
- **`sfx`:** a short sound effect mixed at the word start: whoosh for transitions, pop for callouts, hit for reveals.
  - Bundle a small set of **CC0** SFX files in `apps/server/assets/sfx/`, generated by ffmpeg synth (`anoisesrc`/`sine` + envelopes) at build time or committed as tiny generated WAVs. Document the source. No downloads.
  - Volume −14 dB relative to the voice; ducking is not applied to SFX.
- Limits so it does not get tiring:
  - at most 1 emphasis per 6 s;
  - no emphasis in the first 0.8 s of a scene that starts with a non-cut transition;
  - at most 1 flash per minute.

## 4. Animated subtitles
- New subtitle styles (preset names in Vietnamese in the UI):
  - **`clean`:** the current look, improved: semi-bold, outline 3, shadow, and a safe margin by aspect.
  - **`karaoke`:** a word-by-word highlight using ASS `\k` / `\kf` timings from `words`. Spoken words turn the highlight colour (the brand colour or yellow).
  - **`pop`:** 1–3 words per cue, the current word scales up (`\t` scale 85→105→100 over 120 ms), with a bold, big centered lower-third. The short-video style.
  - **`box`:** white text on a rounded semi-transparent box (`BorderStyle=3`).
- Line breaking keeps phrases together and never leaves one word alone on a line, for Vietnamese and other languages.
- When `words` timing is `estimated` (TASK-040), karaoke/pop still work but use the cue-level highlight instead of exact per-word timing.
- **The gap fix (applies to all styles):** when the gap between consecutive cues is < 0.6 s, extend the previous cue's end to the next cue's start, so subtitles do not blink off. Real pauses (≥ 0.6 s) stay empty. Unit test it with the 19.50→20.03 case seen in the test render.
- The vertical (9:16) default is `pop`; the landscape default is `karaoke`.

## 5. LLM edit plan (new LLM task `editPlan`, tier strong, budget feature)
- Input:
  - the scenes (narration, visual kind, duration);
  - the word list with times (compact: `w|start`);
  - the profile style and the edit preset (§6);
  - the aspect.
- Output, zod-validated:
  ```ts
  { transitions: { afterSceneId: string, type: TransitionType, durationSec: number }[],
    motions: { sceneId: string, preset: MotionPreset }[],
    emphasis: { sceneId: string, wordIndexStart: number, wordIndexEnd: number, effects: ("punch_in"|"callout"|"flash"|"sfx")[], calloutText?: string /* ≤ 24 chars */ }[],
    subtitleStyle?: SubtitleStyleId }
  ```
- Validate and clamp in code with the §3 limits, unknown ids dropped, and the duration bounds. Anything invalid falls back to the default rhythm for that item.
- Without the LLM (budget economy, or a failure), a code fallback picks emphasis words:
  - numbers;
  - words in the title;
  - words after "bí mật / sự thật / quan trọng / không ngờ";
  - the last sentence of the hook.
- The plan is stored on the timeline (`edit_plan` json) and is visible and editable before the render.

## 6. Edit presets per profile
- Presets:
  - **`calm`** (documentary): dissolves, slow motion, `clean` subtitles, rare emphasis, no SFX;
  - **`energetic`** (shorts): cuts plus smooth slides, `pop` subtitles, emphasis every ~8 s, SFX on;
  - **`news`**: wipes, `box` subtitles, callouts for numbers and dates;
  - **`story`**: fades, `karaoke`, punch-in on emotional words.
- A profile picks a preset plus overrides: subtitle style, font size, highlight colour, SFX on/off, emphasis frequency.
- A project can override.
- The preset steers the LLM plan and the fallback.

## 7. UI
- **Timeline page:**
  - a transition chip between scenes (click to change the type and duration);
  - a motion select per scene;
  - an emphasis list with word ranges highlighted in the narration text (click words to add or remove);
  - a subtitle style picker with a live preview: a short HTML/CSS mock of the style, not a render;
  - "Tạo kế hoạch dựng bằng AI" regenerates the plan.
- **Profile page:** an "Phong cách dựng" section with the presets and overrides.
- **Render:** a "Xem nhanh 10 giây" quick preview renders a 10 s excerpt around a chosen scene at low resolution, to check the effects fast.

## 8. Tests (no network; mock LLM; ffmpeg arg builders tested as strings; any real ffmpeg run only if the existing render tests already do so)
- The xfade chain: offsets from the timeline starts; tail extension; voice sync within 1 frame; grouping over 12 clips; the concat fallback when xfade is missing.
- The default rhythm: no more than 2 identical transitions in a row; motion directions alternate.
- ASS output:
  - karaoke `\k` durations sum to the cue length;
  - pop word scaling tags;
  - box style;
  - the callout layer does not overlap the subtitle margin;
  - Vietnamese text is escaped.
- The gap fix: a gap < 0.6 s is closed, and a gap ≥ 0.6 s is kept (including 19.50→20.03).
- Emphasis limits: once per 6 s, flash once per minute; SFX mixed at the word start at −14 dB.
- The editPlan validation clamps or falls back; the code fallback picks numbers and title words.
- Presets map to the expected defaults; profile and project overrides win.
- Web: the transition chip edit, emphasis word toggling, and the style preview render.
