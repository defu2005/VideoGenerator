## 1. TASK-138: Local GC Race Condition và Độ phức tạp S3 Purge

### 1.1. Tái hiện lỗi (Reproduction)
- **Local GC Race (`tmp/codex-review-138-late-local-ref.ts`)**:
  - Chạy trên fix1:
    ```json
    {"addedBeforeWriteTransaction":true,"result":{"marked":0,"cleared":0,"purged":1,"bytes":15,"eligible":1,"eligibleBytes":15,"errors":0},"referencedFileStillExists":false,"timelineStillReferencesFile":true}
    ```
    Tệp bị xóa oan dù timeline đã tham chiếu ngay trước transaction ghi (`immediate`).
- **S3 Purge Complexity**:
  - Trong fix1, `currentReferenced(sha)` tại các async fence và trong delete transaction gọi `collectReferences`, dựng và quét lại toàn bộ đồ thị tham chiếu với mỗi SHA trong danh sách purge.

### 1.2. Giải pháp thực hiện trong Fix Pass 2
- **Hàm kiểm tra tham chiếu mục tiêu trực tiếp trong DB (`isTargetReferencedInDb`)**:
  - Triển khai trong `apps/server/src/storage/references.ts`.
  - Thực hiện kiểm tra có mục tiêu (targeted) trực tiếp trên DB hiện tại ngay dưới transaction ghi (`immediate` write lock) của SQLite:
    - Quét các bảng tham chiếu dự án `PROJECT_TABLES`, giải mã các cột JSON legacy (`visitProjectFileReferences`).
    - Quét các bảng thư viện/chia sẻ `SHARED_FILE_TABLES` và `clip_sets` không thuộc dự án.
    - Kiểm tra trạng thái dự án đang bận (`busyProjects`) và dự án được bảo vệ (`PROTECTED_PROJECT_ID`).
    - Đối chiếu các alias đường dẫn và alias SHA thông qua bảng `artifacts`.
    - **Không** quét đĩa hay băm lại toàn bộ đồ thị dưới khóa ghi.
    - Nguyên tắc fail-safe: nếu không thể chứng minh tệp/SHA không còn tham chiếu, giữ lại tệp (`return true`).
- **Khắc phục Local Purge Race**:
  - Trong `FileGc.run()`, bên trong transaction `purged`:
    ```ts
    if (referencesForPath(graph, file.path, this.root).length > 0) return false;
    if (isTargetReferencedInDb(this.db, this.root, { path: file.path }, { now: startedAt, postPublishDays: settings.postPublishDays }, this.artifacts)) {
      return false;
    }
    ```
  - Kết quả kiểm chứng lại với `tmp/codex-review-138-late-local-ref.ts`:
    ```json
    {"addedBeforeWriteTransaction":true,"result":{"marked":0,"cleared":0,"purged":0,"bytes":0,"eligible":1,"eligibleBytes":15,"errors":0},"referencedFileStillExists":true,"timelineStillReferencesFile":true}
    ```
    Tệp được bảo toàn an toàn khi có kết nối đồng thời thêm tham chiếu.
- **Tối ưu S3 Purge**:
  - Trong `FileGc.runBlobs()`:
    ```ts
    const currentReferenced = (sha: string) => {
      if (this.isReferencedInGraph(baseGraph, sha)) return true;
      return isTargetReferencedInDb(this.db, this.root, { sha256: sha }, { now: this.now(), postPublishDays: this.settings().postPublishDays }, this.artifacts);
    };
    ```
  - Loại bỏ hoàn toàn O(N) full graph rebuilds trong `runBlobs`.
  - Đảm bảo kiểm tra targeted recheck tại từng async fence (trước claim, sau backup, sau remote delete) và ngay trong transaction `DELETE FROM blobs`.

## 2. TASK-139: Dấu vết tươi mới hoàn chỉnh cho Compose Plan và Preview

### 2.1. Tái hiện lỗi (Reproduction)
- **Stale plan on cleared image (`tmp/codex-review-139-cleared-image.ts`)**:
  - Chạy trên fix1:
    ```json
    {"currentTimeline":{"path":null,"seconds":2},"actualPreview":{"basis":"timeline","source":{"kind":"still","candidateId":"old","path":"visuals/old.jpg","motion":"static"},"seconds":2},"reusedStalePlan":true}
    ```
    Do ảnh bị xóa thành PLACEHOLDER (path null), logic fix1 chỉ kiểm tra visual ảnh (`v.kind === "IMAGE" && v.path`) nên bỏ qua, dẫn đến việc tái sử dụng plan cũ chứa ảnh cũ.

### 2.2. Giải pháp thực hiện trong Fix Pass 2
- **Cập nhật `isSavedPlanCurrent` trong `apps/server/src/preview/planSource.ts`**:
  - Kiểm tra độ khớp FPS giữa `saved.fps` và `timeline.target.fps`.
  - Kiểm tra trường hợp ảnh bị xóa / chuyển sang placeholder: Nếu timeline chỉ có PLACEHOLDER hoặc không có visual ảnh mà saved plan có shot still có đường dẫn, lập tức coi plan là cũ (`return false`).
  - Kiểm tra mọi visual trong scene, so sánh danh sách đường dẫn và candidateId với các shot không bị khóa (`!shot.locked`).
  - Kiểm tra tính hiện diện của đồ họa timeline (`timeline.graphics`) đối với cảnh tương ứng.
  - Bảo toàn tuyệt đối các shot đã khóa (`locked: true`).
- **Kết quả kiểm chứng lại**:
  - Chạy `npx tsx tmp/codex-review-139-cleared-image.ts`:
    ```json
    {"currentTimeline":{"path":null,"seconds":2},"actualPreview":{"basis":"timeline","source":{"kind":"still","candidateId":null,"path":null,"motion":"static"},"seconds":2},"reusedStalePlan":false}
    ```

