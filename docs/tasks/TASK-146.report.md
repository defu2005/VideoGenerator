The cap is checked only for beat-derived punch_ins (`tooClose` in `packages/shared/src/motion/beatMotion.ts` lines 24–55), while `lastPunchAt` is updated by every final punch_in. So a cycle-derived punch_in can land within `capSec` of a beat punch_in. This limit is not fixed.
