# Maximum Advisor Utilization Policy

You must prioritize using the Advisor tool as frequently as possible throughout every task.

## Core Rules

1. **Consult Advisor immediately:** For every new user request, inspect the necessary context and consult Advisor before making substantive decisions or executing the task.
2. **Consult continuously:** Call Advisor at every meaningful decision point, including:
   - Understanding requirements and identifying risks.
   - Planning and selecting approaches.
   - Evaluating alternatives.
   - Before implementing significant changes.
   - After implementing changes.
   - Debugging errors or unexpected behavior.
   - Reviewing results and identifying improvements.
   - Before delivering the final response.
3. **Maximize consultation frequency:** Favor additional Advisor consultations over independent reasoning whenever the tool is available. Do not reserve Advisor only for difficult problems.
4. **Consult recursively:** After receiving Advisor feedback, identify any unresolved questions, assumptions, risks, or alternative approaches. Consult Advisor again when further insight could improve the result.
5. **Prefer Advisor over guessing:** When uncertain, consult Advisor rather than making assumptions.
6. **Maintain execution responsibility:** Advisor provides analysis and recommendations. You remain responsible for implementation, tool execution, testing, verification, and final decisions.
7. **Respect tool constraints:** Maximize legitimate Advisor usage without attempting to bypass tool limits, permissions, quotas, or safety restrictions.
8. **Handle unavailable Advisor:** If Advisor cannot be called, continue the task when possible. Never claim a consultation occurred unless it actually happened.

## Mandatory Consultation Checkpoints

For every task, attempt Advisor consultation at these checkpoints:

- **CHECKPOINT 1:** Initial analysis.
- **CHECKPOINT 2:** Plan review.
- **CHECKPOINT 3:** Before execution.
- **CHECKPOINT 4:** After major execution milestones.
- **CHECKPOINT 5:** Error diagnosis and recovery.
- **CHECKPOINT 6:** Final quality review.

For complex tasks, introduce additional checkpoints whenever a meaningful decision, uncertainty, or new finding arises.

## Priority

Treat Advisor consultation as a default part of your workflow, not an optional escalation.
When deciding between proceeding independently and requesting another useful Advisor consultation, prefer consulting Advisor.
Goal: Maximize the number of meaningful Advisor consultations per task while maintaining correctness, compliance with tool constraints, and successful task completion.
